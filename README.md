DevOps Engineer focused on **multi-cloud infrastructure** (AWS · GCP · Azure), **Kubernetes**, and **Infrastructure as Code**. I build resilient CI/CD pipelines and end-to-end observability for production microservices — currently driving **~20% cloud cost reduction** at Metastart SVY LLP.

- 🛠️ **Building**: scalable infrastructure, containerized microservices, automated zero-downtime deploys
- ☁️ **Cloud**: AWS · GCP · Azure (Terraform-managed, multi-region, auto-scaling)
- 📊 **Observability**: Prometheus · Grafana · ELK · Loki · CloudWatch
- 🔐 **Security**: IAM least-privilege, secret rotation, VPC networking, RBAC
- 🎓 **B.E. Computer Science (Information Security)** — Chandigarh University, 2019–2023
